# Feature names

Our own names for user-visible features. Do not use another company's product or feature names.

| Name | What it is |
| --- | --- |
| Lens | A saved chart or report |
| Focus board | Home screen: ranked insight cards on where the value is and what to work on |
| Roles matrix | Heat grid of roles × features |
| Feature pulse | Per-feature frequency, adoption, stickiness, retention, conversion |
| Thumbs | Built-in micro-survey for feature appreciation |
| Journeys | Funnels (ordered steps with conversion) |
| Comebacks | Retention cohorts |
| Trails | User paths |
| Switches | Feature flags |
| Trials | Experiments |
| Rewind | Session replay |
| Crash log | Error analysis |
| Hotspots | Heatmaps |
| Wire | Agent-driven installation |
| Feature map | `openlens.features.yaml`, the declared features of an app |
| Value moment | The early behaviour that best predicts a user staying |
| Stick drivers | Features ranked by retention lift |
| Churn points | Last features and steps seen before users go inactive |
