# 🔭 OpenLens v0.2.0

**Numbers you can trust, on any platform, maintained by itself.** v0.2.0 fixes a data-freshness bug of v0.1.0, runs on Kubernetes, counts days in the team's time zone, and puts maintenance on autopilot: dependency updates, releases and upgrades of running installs happen without a person.

## ⚠️ Upgrade now if you run v0.1.0

In v0.1.0, **events that arrived after the server's first query could stay out of the dashboards until a restart.** DataFusion caches directory listings with no expiry, and the runtime shared by every query kept the first list it saw. No data was lost, because events were written to disk, but the numbers froze. v0.2.0 turns that cache off, and a regression test guards it.

## ✨ Highlights

- ☸️ **Kubernetes, ready for an agent.**
  - A Helm chart (`oci://ghcr.io/philippe-arnd/charts/openlens`) and a Kustomize base, with nothing to configure: a generated admin token, a PVC, an optional Ingress and a hardened pod.
  - Nightly backups as a CronJob.
  - The agent guide [docs/deploy/kubernetes.md](../deploy/kubernetes.md) has a check for every step.
- 🌍 **A time zone per project.** Days and weeks of every KPI start in the team's zone (`openlens-cli init --timezone Europe/Paris`), not in UTC.
- 🎬 **A replay player you can steer:**
  - the session's events as markers on the timeline;
  - a list of events that follows the playhead;
  - speeds from 0.5× to 8×, keyboard shortcuts, and a phone layout.
- 📱 **Every page works on a phone** (390 px), in light and dark, and meets WCAG AA. The navigation is a left sidebar, collapsible to icons.
- ⚡ **About 2× faster boards on real projects.** That's with anonymous visits and logins: 0.8 s on 368k events, 3.7 s on 2.2M, on one vCPU.
- 🧹 **Cleaner numbers:**
  - robots are filed apart;
  - the team's own accounts are left out (`identify(id, { internal: true })`);
  - resent batches are stored once;
  - form submits inside web components are captured.
- 🔌 **Server SDKs for Go, Ruby and PHP**, next to Node and Python.
- 🔐 **Sign-in by email** for invited users, rate limits on `/capture`, and a security pass:
  - proxy-aware client addresses;
  - no open redirects;
  - RustSec checks in CI;
  - SQLite 3.54.1.

## 🤖 Maintenance on autopilot

- **Dependencies:** Renovate groups the updates and merges them once CI is green. A failure becomes an issue.
- **Security:** advisories are tracked as an issue that closes itself once the check is green again.
- **Releases:** a release train cuts a stable release every Tuesday when the nightlies are green.
- **Base images:** they are refreshed monthly.
- **Running installs update safely:**
  - `:latest` now means the newest stable release; `:0.2` follows the patches of a minor; `:edge` follows `main`;
  - the binary backs up its data when the version changes, and refuses data written by a newer release;
  - a stable release can redeploy a Coolify instance by itself;
  - the footer says when an update is available.

## 🚀 Install or upgrade

```sh
docker run -d -p 8686:8686 -v openlens-data:/data ghcr.io/philippe-arnd/openlens:0.2
helm install openlens oci://ghcr.io/philippe-arnd/charts/openlens -n openlens --create-namespace
```

**Coolify:** redeploy the template; it follows `:latest`. On the first start of v0.2.0, OpenLens copies the data to `backups/upgrade/` before anything else, so leave room for one copy of it.

## ⚠️ Changes in behaviour

- **No automatic `default` project.** Agents create one per app with `openlens-cli init --name <app>`. `OPENLENS_PROJECT_KEY` still creates `default` for CI and demos. An existing `default` project is kept; delete it with `openlens-cli delete-project default --confirm default` if it is unused.
- **`:latest` is the newest stable release**, where it used to follow `main`. Use `:edge` for `main`.
- **Days follow the project's time zone** once one is set. Projects stay in UTC until then, so nothing changes by itself.
- **The navigation moved** from the top bar to a left sidebar.

The data on disk is compatible, and nothing needs to be migrated by hand.

## 🧭 Known limitations

- **One node:** a single process with local disk.
- **npm:** `@openlens/web` is not on npm yet. Use the script tag or a `file:` dependency.
- **Sessions are cut at UTC midnight** by the SDK, because the browser does not know the project's zone.
- **Small samples:** insight cards wait for 8 or more users per compared group.
