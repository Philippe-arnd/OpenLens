Zero human setup

Built for apps that agents write and maintain. Every server serves its own wiring guide at /agents.md.

  1. Deploy one binary or one container. No configuration: the admin token and keys generate themselves.
  2. Your agent wires the app: one script, identify(user, {role}), and a small feature map of features, success moments and roles.
  3. History on day one: it backfills from the app's own database, then checks the wiring.
  4. The PM gets a login link and opens a board that already ranks what matters.
  5. Agents stay in the loop over MCP: insights, KPI reports, user timelines, errors, flags, surveys and read-only SQL.

Everything a product team needs, in one place

Focus board

Three to seven ranked insights: stick drivers, value moment, churn points, blind spots, value journeys.

KPIs by role and release

Active users, stickiness, retention, resurrection, sessions, tasks, errors and Web Vitals, compared release to release.

Feature pulse

Adoption, frequency, completion and task time for every feature, and a roles × features grid.

Journeys and funnels

The paths into each success event and the step where people drop off.

Flags and experiments

Rollouts by percentage, role or account. Each flag is a cohort with a significance test.

Micro-surveys

One question right after a success, with results by role.

Session replay

Lazy-loaded recorder, inputs always masked, linked from every insight.

Errors

Grouped by cause, with source maps and the replay of the session.

Heatmaps

Clicks, rage clicks and scroll depth, over a real recorded visit of the page.

Weekly digest

On the dashboard, over MCP, and by email if you want it.
